# Outreach Messages: Web do 24h Pilot

## Pravidlá použitia

- Posielaj ručne, nie automatizovane.
- Pred odoslaním si pozri web alebo profil firmy.
- Doplň konkrétnu poznámku do hranatých zátvoriek.
- Nepoužívaj fake referencie.
- Nesľubuj garantovaný predaj ani garantované SEO pozície.
- `Do 24h` vždy formuluj ako podľa rozsahu a dodaných podkladov.
- Ak si nie si istý kontaktom alebo relevanciou, neposielaj.

## 1. Cold email pre lokálnu firmu

Predmet:

```txt
Rýchly návrh webu pre [NÁZOV FIRMY]
```

Správa:

```txt
Dobrý deň [MENO],

pozeral som [KRÁTKA KONKRÉTNA POZNÁMKA K WEBU / PONUKÁM / SLUŽBE].

Testujeme pilot Web do 24h: za fixnú cenu pripravíme štruktúru webu, texty, CTA smerovanie, základné SEO podklady a WordPress-ready obsah na kontrolu.

Nie je to garancia predaja ani SEO pozícií. Je to rýchly obsahový a štruktúrny štart podľa rozsahu a dodaných podkladov.

Pilotné ceny:
- Start: 299 €
- Pro: 699 €

Ak chcete, pošlem vám krátky brief a dohodneme, či to pre vás dáva zmysel.

S pozdravom
[MENO]
Rubberduck / LE Studio
```

## 2. Follow-up po 3 dňoch

Predmet:

```txt
Re: Rýchly návrh webu pre [NÁZOV FIRMY]
```

Správa:

```txt
Dobrý deň [MENO],

len krátko nadväzujem na správu nižšie.

Ak teraz web neriešite, v poriadku. Ak áno, pilot Web do 24h môže byť rýchly spôsob, ako dostať štruktúru, texty, CTA a WordPress-ready obsah na kontrolu bez dlhého procesu.

Stačí odpísať „pošlite brief“ a pošlem krátke otázky.

S pozdravom
[MENO]
```

## 3. DM pre freelancerov

```txt
Ahoj [MENO],

videl som, že robíš weby / dizajn / WordPress.

Testujeme LE Studio workflow pre Web do 24h: z briefu pripraví štruktúru, texty, CTA, SEO základ a WordPress-ready obsah. Nie je to náhrada freelancera, skôr rýchly podklad pre dodanie alebo pilot klientovi.

Hľadám 2-3 freelancerov na pilotnú spoluprácu. Fixný rozsah, jasné výstupy, bez fake garancií.

Chceš, aby som poslal ukážku briefu a výstupu?
```

## 4. Správa pre web agentúry

Predmet:

```txt
Podkladový workflow pre rýchle webové briefy
```

Správa:

```txt
Dobrý deň [MENO],

pracujeme na LE Studio workflowe pre Web do 24h. Výstup nie je hotový web bez kontroly, ale štruktúra, texty, CTA, SEO základ a WordPress-ready obsah, ktorý vie agentúra ďalej upraviť a nasadiť.

Môže to pomôcť pri menších klientoch, kde sa veľa času stráca na prvom texte a štruktúre.

Hľadáme pár agentúr na pilotný test. Bez záväzku, bez garancií výsledkov, cieľ je overiť, či výstup šetrí čas.

Ak chcete, pošlem krátky sample flow.

S pozdravom
[MENO]
```

Bez garancií predaja alebo SEO pozícií. Pilot Start je 299 €, Pro 699 €. Ak to dáva zmysel, pošlem krátky brief.
```

[MENO]
```

## 7. Odpoveď na otázku: koľko to stojí?

```txt
Pilotný cenník je jednoduchý:

- Start: 299 €
- Pro: 699 €
- Custom: od 1 200 € podľa rozsahu
- Maintenance: od 49 €/mesiac, ak treba priebežnú starostlivosť

Ceny sú pilotné a závisia od rozsahu a dodaných podkladov. Pred začiatkom by sme si najprv potvrdili, čo presne má byť výstupom, aby nevznikli nejasné očakávania.
```

## 8. Odpoveď na otázku: čo znamená do 24h?

```txt
`Do 24h` znamená rýchle dodanie pri jasnom rozsahu a dodaných podkladoch.

Nie je to garancia pre každý typ projektu. Ak chýbajú texty, logo, kontakty, rozhodnutia alebo je rozsah väčší, termín sa upraví. Férový význam je: rýchly štart webu, nie magický sľub bez podmienok.
```

## 9. Keď chce záujemca ukážku

```txt
Jasné. Pošlem krátky brief a ukážku výstupu.

Typický výstup obsahuje:
- štruktúru stránky
- headline a CTA
- sekcie webu
- FAQ
- základné SEO podklady
- WordPress-ready obsahový payload

Pred publikovaním ide všetko cez kontrolu.
```

## 10. Keď sa pýta, či robíme aj WordPress

```txt
Áno, výstup pripravujeme tak, aby bol použiteľný vo WordPress workflowe.

Dôležité: najprv vzniká obsah a štruktúra na kontrolu. Samotné nasadenie do WordPressu riešime až po schválení výstupu a podľa konkrétneho hostingu/témy.
```
