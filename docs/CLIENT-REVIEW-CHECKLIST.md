# Client Review Checklist: Web do 24h

## Účel

Tento checklist používa klient alebo delivery owner pri kontrole výstupu pred importom, publikovaním alebo finálnym handoffom.

## 1. Názov projektu

- [ ] Názov projektu je správny.
- [ ] Názov firmy je správny.
- [ ] Názov nie je zamenený za interný typ projektu.
- [ ] Slug alebo URL návrh je čitateľný.

## 2. Headline

- [ ] Headline jasne hovorí, čo ponuka robí.
- [ ] Headline nepoužíva nepravdivé alebo prehnané sľuby.
- [ ] Headline neobsahuje garantované predaje, garantované SEO alebo fake claimy.
- [ ] Podnadpis vysvetľuje kontext bez marketingovej hmly.

```txt

```

## 3. CTA

- [ ] Hlavné CTA je jasné.
- [ ] CTA vedie na reálny flow alebo jasný kontakt.
- [ ] Sekundárne CTA má zmysel.
- [ ] CTA nesľubuje výsledok, ktorý nie je garantovaný.

Príklady bezpečných CTA:

- Poslať brief
- Dohodnúť konzultáciu
- Pozrieť ukážku výstupu
- Poslať dopyt

## 4. Sekcie

Skontroluj každú sekciu:

- [ ] Hero
- [ ] Pre koho to je
- [ ] Čo klient dostane
- [ ] Proces
- [ ] Ponuka alebo balíky
- [ ] Dôvera / bezpečné vysvetlenie
- [ ] FAQ
- [ ] Kontakt

Pri každej sekcii over:

- [ ] text je vecný
- [ ] text sedí s realitou
- [ ] text neobsahuje placeholdery
- [ ] text neobsahuje fake referencie
- [ ] text neobsahuje vymyslené čísla

## 5. FAQ

- [ ] FAQ odpovedá na reálne otázky klienta.
- [ ] FAQ nesľubuje právne, finančné alebo obchodné výsledky bez dôkazu.
- [ ] FAQ vysvetľuje limity `do 24h` podľa rozsahu a dostupných podkladov.
- [ ] FAQ jasne hovorí, čo musí klient dodať.
- [ ] FAQ vysvetľuje, čo sa deje pred publikovaním.

## 6. Ceny, ak existujú

- [ ] Ceny sú schválené klientom alebo ownerom ponuky.
- [ ] Ceny sú označené ako pilotné/úvodné, ak ide o pilot.
- [ ] Ceny nie sú vymyslené AI systémom.
- [ ] Ceny majú jasný rozsah.
- [ ] Maintenance alebo mesačné položky majú jasný minimálny rozsah.
- [ ] Text nevyvoláva dojem trvalej garancie ceny, ak to nie je pravda.

## 7. Právne a obchodné tvrdenia

- [ ] Nie sú použité fake referencie.
- [ ] Nie sú použité fake počty klientov.
- [ ] Nie sú použité fake príjmy alebo obraty.
- [ ] Nie sú použité garantované predaje.
- [ ] Nie sú použité garantované SEO pozície.
- [ ] Nie je použité manipulatívne urgentné tvrdenie.
- [ ] Nie sú použité gambling/lottery mechaniky.
- [ ] Všetky tvrdenia sú overiteľné alebo formulované opatrne.

## 8. Kontakty

- [ ] Email je správny.
- [ ] Telefón je správny, ak sa zobrazuje.
- [ ] Kontaktný formulár má jasný účel.
- [ ] Formulár neposiela dáta na neoverené externé služby.
- [ ] Súhlas s kontaktovaním je prítomný, ak sa zbierajú osobné údaje.
- [ ] Klient vie, kam dopyty prídu.

## 9. SEO

- [ ] SEO title je vecný a neprehnaný.
- [ ] SEO description vysvetľuje ponuku bez garancií výsledkov.
- [ ] OG title a OG description sú konzistentné.
- [ ] Kľúčové slová sú prirodzené, nie spamové.
- [ ] Nie je sľubovaná prvá pozícia v Google.

## 10. Zakázané tvrdenia

Výstup sa nesmie schváliť, ak obsahuje:

- garantovaný predaj
- garantovaný príjem
- garantovanú SEO pozíciu
- fake referencie
- fake počty klientov
- fake case study
- fake certifikát
- manipulatívnu urgentnosť
- neoverené právne tvrdenie
- neoverené zdravotné tvrdenie
- vymyslené ceny
- vymyslené médiá

## 11. Finálne rozhodnutie

- [ ] Schválené s P2 úpravami
- [ ] Neschválené, vyžaduje P1 úpravy
- [ ] Blokované P0 problémom
