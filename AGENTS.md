# AGENTS Rules

- Do not touch production DNS.
- Do not modify WordPress deployment runtime.
- Do not modify Caddy or server configuration.
- Do not commit secrets.
- Do not expose WordPress credentials to browser/client bundles.
- Do not generate raw HTML output from workflow generation.
- Do not make the product crowdfunding-first.
- `support-campaign` is one project type only.
- Keep real imports disabled by default.
- Use structured JSON and schema validation.
- Keep restricted wording out of rendered UI and generated output.
